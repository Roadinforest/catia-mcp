# v0.2.0 — WHUCAD-MCP 还原基线

日期：2026-11-22。协议：`whucad-migration`。程序 JSON 版本：3。

## 项目定位

本版本用于将 WHUCAD-MCP 程序序列还原为 CATIA 零件。它提供毕设后续扩展的基础实现，不把自然语言评测题库、LLM API 调用、成绩统计等毕设实验视为本版本的职责。

发布基线保留在 `v0.2.0` 标签；`毕设/MCP` 从此标签建立 `thesis-development` 分支。新增毕设功能在扩展分支提交，不回写或移动基线标签。

## 接口与兼容范围

- 新版协议共 20 个工具，包括 `model_state`、`sol` 和建模、选择工具。
- 服务保存当前草图、特征与选择状态；执行器注入本次会话的 model_id。
- selection 使用 WHUCAD 来源树；topo/mirror_topo 是选择声明标记，不是旧版几何查询接口。
- 弧参数使用弧度，旋转参数沿用原解码角度约定；不得套用旧版 18 工具参数说明。
- 运行时使用随包的 WHUCAD converter 源码。原始来源和哈希保留于 vendor/whucad_converter/provenance.json。
- legacy 与早期 whucad-stateful 实现为依赖完整性和回归兼容保留；不作为本 release 的默认公共入口。
- 公共入口 run.py serve / start-mcp.ps1 固定新版协议，禁止覆盖为旧协议或开启脚本旁路；直接 python -m catia_mcp 仍维持历史 legacy 默认值。

## 相对现有代码的发布整理

新版建模核心 stateful_migration.py 及 converter_semantics.py 与发布整理前、mcp-data-v2 中的实现一致。本次不改变建模语义。

发布整理修改了：版本号和项目定位、converter 默认路径（改为包内 vendor）、独立安装与启动入口、依赖锁、提交白名单、发行说明。执行器采用 mcp-data-v2 已有的独立运行版本。仅附带一个用于验证接口的程序示例，不附带全量数据集。

## 提交边界

纳入：MCP 运行源码、原 converter 运行源码及出处、安装/启动入口、单程序 JSON 执行器、迁移编译库、相关单元测试、工具 schema、一个程序示例、发布说明。

排除并保留在原工作目录：题库和图像、A/B 状态评测、LLM API 配置、密钥、运行日志、CAD 导出文件、全量数据集、虚拟环境、缓存、临时 JSON、个人代理配置、历史分析和探测脚本。历史 README 和被整理的配置另存于原工作区的“发布准备记录”，不纳入代码发行。

本次只使用明确路径暂存；提交前核对暂存文件清单、敏感内容和生成物。新 MCP 工作目录由发行提交克隆，确保没有夹带未提交实验文件。

## 验证与已知范围

验证结果记录在同目录 `v0.2.0-validation.md`。本次发布以源码、接口和可搬运运行验证为主，不重新跑全量 CAD 数据集。

原 v2 数据集统计为 146,066 份程序，其中 145,918 份静态校验通过，148 份存在非正半径。它们是数据集已有统计，不代表此发行已全量通过几何验收。

CATIA V5、许可和基础 Python 属于外部运行条件。虚拟环境不作为可搬运文件提交；迁移目录后使用 setup.ps1 重建。

本地 Git release 标签与远程 GitHub Release 是两件事；本次不把本地提交或标签存在表述为已经上传 GitHub。
